# Support

For setup and integration guidance, visit the [Inttegro MCP
documentation](https://studio.inttegro.dev/inttegro-mcp).

Report reproducible extension defects in the [Inttegro AI issue
tracker](https://github.com/inttegro/ai/issues). Include the Visual Studio Code
version, extension version, operating system, and the relevant extension or MCP
output. Never include access tokens, API keys, customer data, or production
exports.

Report security issues privately as described in the repository's [security
policy](https://github.com/inttegro/ai/security/policy).
