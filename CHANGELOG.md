# Changelog

## 0.1.0 — 2026-11-09

- Introduce the single `@inttegro/ai` command-line package.
- Add read-only MCP and OAuth diagnostics through `inttegro-ai doctor`.
- Add maintainer routing evaluations through `inttegro-ai eval routing`.
- Bundle the versioned routing corpus and candidate metadata so evaluations run
  from the installed package without a repository checkout.
